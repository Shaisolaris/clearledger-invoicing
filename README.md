# ClearLedger

Invoicing app with client management and PDF-style output.

**[Live Demo](https://shaisolaris.github.io/clearledger-invoicing/)**

## Features

- Invoice builder with line items and totals
- Client directory and status tracking
- Invoice list with payment states
- Print-ready invoice layout

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Tech

Next.js · React · Tailwind CSS
